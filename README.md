# House of Gambling — Direct iGaming Advertiser Landing

Интерактивный промо-лендинг партнерской сети в iGaming вертикали с анимацией барабанов слотов, калькулятором доходности и мультиязычностью (RU/EN).

**Демо**: [https://lelyaler.github.io/Animation-web/](https://lelyaler.github.io/Animation-web/)

---

## Реализованный функционал

- **Интерактивный баннер слотов**:
  - CSS-анимация непрерывного вращения вертикальных барабанов (keyframes 60 FPS).
  - Ускорение вращения и имитация спина по клику на кнопку «Крутить слоты».
  - Адаптивная трансформация ленты выплат и барабанов на мобильных экранах.
- **Интерактивный калькулятор доходности**:
  - Динамический пересчет прибыли по моделям CPA, RevShare и Hybrid в реальном времени.
  - Двойные ползунки диапазона (первые депозиты и средний чек игрока).
- **Локализация (RU / EN)**:
  - Клиентский переключатель языка с сохранением выбора пользователя в `localStorage`.
- **UI и компоненты**:
  - Модальные окна на нативном HTML5 `<dialog>` (регистрация, вход, чтение кейсов).
  - Аккордеон часто задаваемых вопросов (FAQ).
  - Кастомный скроллбар ленты выплат.
  - Анимации появления секций через `IntersectionObserver`.

## Стек технологий

- **HTML5 & CSS3**: семантическая разметка, CSS Grid / Flexbox, CSS анимации и переменные.
- **JavaScript (ES6+)**: модульная компонентная архитектура (ES Modules) без сторонних фреймворков.
